# hv-assets

Creative asset library for Happen Ventures. Powers the live Design Center at https://hv-design-center.netlify.app and the gallery reads these folders directly, so anything committed here appears on the site within about a minute.

## How to add images

Easiest: use the uploader at https://hv-uploader.netlify.app - drop a photo, rename it, pick a category, click upload. Or commit files straight into the right folder below.

## Folders

| Folder | What goes in it |
| --- | --- |
| hv-branded-photos | Branded / on-site photography of Happen Ventures work |
| stock-photos | General stock imagery (sustainability, warehouses, teams) |
| case-study-images | Visuals tied to specific projects, results, before/afters |
| client-logos | Partner and customer logos |
| logos | Official Happen Ventures logo files |
| hv-logo-stock | HV logo lockups, variations, stock logo treatments |

## Naming

Lowercase, hyphens instead of spaces (amazon-warehouse-reuse.jpg). Keep files under ~5 MB. Formats: jpg, png, svg, webp, gif. The uploader cleans names automatically.
